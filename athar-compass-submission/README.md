# بوصلة الأثر (Athar Compass)

كفاءة الأثر في مبادرات القطاع الثالث · هاكثون تحليل بيانات القطاع الثالث · الفكرة: **تحسين أداء البرامج والمبادرات**

**سؤال القرار:** هل يرتفع الأثر بنفس نسبة ارتفاع التمويل؟ وهل تختلف كلفة الشخص المتأثر باختلاف حجم المبادرة ونوعها؟

## كيف يُشغَّل المشروع
1. افتح `analysis.ipynb` في Google Colab (أو Jupyter).
2. اختر **Runtime ← Restart session and run all**.
3. الدفتر ينزّل البيانات تلقائيًا من Kaggle عبر `kagglehub` (يحتاج إنترنت). وإن وضعت الملف الأصلي في `data_raw/interdependence-orgs.csv` فسيستخدمه.
4. المخرجات تُكتب في `data_clean/` و`outputs/figures/` و`report/`.

## محتويات التسليم
| المسار | المحتوى |
|---|---|
| `analysis.ipynb` | التنظيف والتحليل والتحقق وإنتاج التقرير (مشغَّل ومخرجاته محفوظة) |
| `data_clean/ngo_clean.csv` | البيانات بعد التنظيف مع عمودي `qc_flags` و`in_analysis` |
| `data_clean/cleaning_log.csv` | سجل التغييرات: كل تعديل وسببه |
| `data_clean/data_dictionary.md` | قاموس الأعمدة والافتراضات |
| `outputs/figures/` | ثلاثة رسوم |
| `report/executive_summary.pdf` | التقرير التنفيذي (صفحتان مع مثال توضيحي وثلاثة رسوم) |
| `ai_usage_log.md` | توثيق استخدام الذكاء الاصطناعي |
| `requirements.txt` | المكتبات المطلوبة |

## البيانات
- **المصدر:** Interdependence NGOs by Funding, Reach، المؤلف: utkarshx27، على Kaggle: https://www.kaggle.com/datasets/utkarshx27/interdependence-ngos-by-funding-reach
- **المحتوى:** 155 منظمة غير ربحية من منظمات المجتمع المدني (غالبًا أمريكية)، كل صف منظمة، ولا توجد بيانات أفراد أو بيانات اتصال.
- **الرخصة:** *(تُستكمل من صفحة المجموعة على Kaggle قبل التسليم؛ لم تُتحقق بعد)*
- النسخة الأصلية لا تُضمَّن في التسليم، ويُنزَّل الملف من المصدر.

## ملخص قواعد التنظيف
حذف عمودين، وتحويل التمويل السنوي إلى أرقام (`?` تصبح فارغة)، والتمويل الصفري أو أقل من 1,000 دولار وعدد الموظفين غير المنطقي يصبحان فارغين. **لا يُحذف أي صف**: يُعلَّم المكرر المتضارب والأثر المقدّر 1,000,000 بالضبط في `qc_flags` ويُستبعدان من التحليل. التفاصيل في `cleaning_log.csv`.

## أهم النتائج
عيّنة التحليل 54 منظمة من 155.
- الثلث الأعلى تمويلًا هو الأغلى كلفة للشخص المتأثر (وسيط 514 دولارًا مقابل 186 و34)، والفرق يصمد بعد حذف القيم الطرفية.
- الترتيب بين الصغيرة والمتوسطة غير مستقر، ولا نبني عليه استنتاجًا.
- لا فرق دال بين الأنواع (Education وMedia وCommunity).

## حدود التحليل
العيّنة صغيرة (35% من الصفوف)، والأثر تقدير غير موحّد بين المنظمات، والعلاقات ارتباط لا سببية، والبيانات ليست ممثلة للقطاع كله (منظمات مجتمع مدني غالبًا أمريكية)، والرخصة تحتاج تأكيدًا.
